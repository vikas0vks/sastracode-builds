# SastraCode — builds

Ready-to-install releases of SastraCode, a coding assistant for Android that runs on your phone and
works against your projects. The application source is not published here.

## Install

1. Download the APK below.
2. Allow installation from unknown sources when prompted (Settings → Security, or the system prompt
   shown by the downloader).
3. Open the APK and install.

SastraCode is sideload-only. It is not distributed through an application store.

## First run

Open a project folder, choose a model endpoint in Settings (any OpenAI-compatible or
Anthropic-compatible API; local servers such as Ollama need no key), and ask for a task.

Files are provided for personal use. Source, licensing, and contribution rules live with the private
development repository.
